# AI-Powered Government Scheme Fulfillment Engine

The project is a FastAPI backend with a Flutter client that helps citizens discover and apply for government schemes more easily.

## Implemented Modules

- Module 1 - Citizen registration, login, JWT refresh, and profile management
- Module 2 - Automatic mock DigiLocker profile, land record, and document retrieval
- Module 3 - Government scheme knowledge base, PDF upload, document processing, and scheme search
- Module 4 - AI Eligibility & Recommendation Engine Objective



## Tech Stack

- Flutter
- FastAPI
- MySQL
- Bhashini / Whisper
- ChromaDB
- FAISS
