# AI-Powered Government Scheme Fulfillment Engine

The project is a FastAPI/MySQL backend with a Flutter client for helping citizens
discover and fulfil government-scheme applications.

## Implemented modules

- Module 1 — citizen registration, authentication, JWT refresh, and profile management
- Module 2 — automatic mock DigiLocker profile, land-record, and document retrieval

See the [Module 2 implementation report](docs/MODULE_2_REPORT.md) and
[backend setup guide](backend/README.md).

## Tech Stack

- Flutter
- FastAPI
- MySQL
- Bhashini / Whisper
- ChromaDB
- FAISS
